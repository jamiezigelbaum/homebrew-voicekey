# VoiceKey Homebrew Tap

Install [VoiceKey](https://github.com/jamiezigelbaum/VoiceKey), a macOS menu
bar app that turns a hotkey into a live voice conversation with an AI
assistant:

```zsh
brew tap jamiezigelbaum/voicekey
brew install --cask voicekey
```

Builds are Developer ID signed and notarized.
